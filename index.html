EcoDetect: Lightweight Real-Time Recyclable Waste Detection Using YOLOv11n Trained on LLM-Guided Synthetic Data

Ahsan Farabi Md. Abdul Ahad Minhaz Israt Khandaker Ibrahim Khalil Shanto Md. Tanvir Raihan

Department of Computer Science and Engineering — United International University, Dhaka, Bangladesh

Paper Code Dataset Talk
Abstract

Turning text into training data

Improper disposal of recyclable waste creates significant challenges for urban waste management and the environment. Manual sorting is inconsistent and economically unfeasible, especially in resource-limited areas.

We present EcoDetect — a lightweight, real-time recyclable waste detection system designed for edge deployment. Rather than collecting labeled real-world data, we leverage LLM-guided prompt engineering to generate synthetic training images at scale, covering three waste classes: plastic, paper, and aluminum.

Tested on a completely unseen real-world holdout set, EcoDetect achieves 78.9% precision, 76.5% recall, and 81.1% mAP@0.5 — with only 2.59M parameters and 6.4 GFLOPs.

Methodology

A synthetic-first pipeline

EcoDetect eliminates manual data collection entirely. Large language models generate structured, scene-diverse prompts. These feed text-to-image models to produce realistic training images, which are then annotated and augmented via Roboflow before fine-tuning YOLOv11n.
